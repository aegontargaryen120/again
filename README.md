# Again -- the tool for managing needless tasks!

> [!WARNING]
> This tool is a work-in-progress.

## Quick Start

```console
$ cd src/
$ make
$ ./again --help
```

## About tests

For this option to work, the tests need to be implemented as follows:
* For each different test function, create a separate file. **DO NOT DECLARE A MAIN**.
* Then, create a `main.c` which runs all the tests.
