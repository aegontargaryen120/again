# Again - the tool for managing every needless task!

> Again is an interactive tool for automating needless tasks, like git setup, git push, git create, and more planned.
> **NOTE:**
> The script assumes that you have a `name.py` with a `name` variable containing your account name.
> This is for macOS, so the script uses `/Users/{dir_name}/code/LICENSE.txt`
> You can either edit the source code, or prepare the `name.py` file and the `LICENSE.txt` file.

## Quick start

```bash
./again
>> help
```

This will tell you the different commands available and what they do
